# 雕塑巡展运输与无障碍开放

协调雕塑巡展的运输安装、作品状况与无障碍公教开放。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括巡展策展团队、作品出借方、艺术品承运安装人员、公教与无障碍服务人员。

资料所依据的领域事实如下：

- 巡展汇集九十二位创作者的一百零四件组作品
- 展览分三个叙事单元并跨地域交流
- 美术馆策划了邀请视障和残障观众参与的触摸活动

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
